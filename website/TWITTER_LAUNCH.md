## Option 4: Technical Audience

🧵 Thread: Introducing NetChain - Proof of Internet Blockchain

1/ We built a Layer-1 blockchain with a completely novel consensus mechanism: Proof of Internet (PoI)

Validators are selected based on measured network metrics, not hashpower or stake.

2/ How it works:
• Nodes measure their download/upload speeds, latency, and uptime
• Peers attest to each other's metrics (prevents gaming)
• Anti-gaming algorithms detect outliers and fraud
• Validator selection weighted by verified network performance

✨ Rust 2021 (performance & safety)
✨ libp2p (decentralized networking)
